# A2-OOP-Smart-Shopping-Cart-Continuation

This Smart Shopping Cart System is a Java-based application that demonstrates Object-Oriented Programming concepts such as encapsulation, inheritance, and polymorphism. It extends the original Assignment 1 system by introducing OnlineShoppingCart and InStoreShoppingCart as derived classes, along with additional Product, Customer, and Payment classes. The system allows users to manage shopping cart information, calculate purchase totals, apply discounts and delivery fees, update product quantities, and simulate payments using Card or QR.
